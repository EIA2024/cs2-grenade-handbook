# 02 · 资料格式

## 固定层级与自由层级

```text
EIA道具合集.zip
└─ EIA道具合集/
   └─ Dust2/
      ├─ CT/
      │  └─ A大/
      │     └─ A大防守烟/
      │        ├─ 站位.png
      │        ├─ 瞄准.jpg
      │        └─ 说明.txt
      └─ T/
```

第一层只允许一个合集目录，合集名不必与 ZIP 文件名一致。地图名称使用英文，可含数字、空格、下划线和短横线；地图下的子目录只能是 CT 或 T。允许包只提供一个阵营，软件新建地图时会同时建立两个。

CT/T 以下可以有自定义分类。合集目录计为第 0 层，最深目录为第 20 层（路径最多 21 段目录名）。图像角色和说明文件名固定，分类及道具名称自由。一个目录包含约定的图片或说明文件时会识别为道具条目；也可包含更深的子目录。

## 图片与文字

- 图片文件名必须为“站位”或“瞄准”，扩展名可以是 `.png`、`.jpg`、`.jpeg`，不区分扩展名大小写。
- 同一目录中同一用途只能有一张图。例如站位.png 与站位.jpg 同时存在会标记错误。
- 图片按实际 PNG/JPEG 内容和解码结果校验，不只检查扩展名。
- 单张图片最多 32 MB、8000 万像素。显示按需缩小解码，不改变保存的原图。
- 说明文件为 UTF-8 的“说明.txt”，上限 1 MB；缺少时按空说明处理。
- 图不齐、损坏或说明无法读取的条目不会进入正常对局列表，可在编辑器中修复。
- 1.1.1 起，ZIP 导入和导出仅允许以上两类图片和说明.txt，拒绝其他附件（包括脚本、可执行文件、快捷方式、desktop.ini）。旧包若带附件，请先在副本中移走附件再导入；原始 ZIP 不会被软件修改。

## 导入保护

拒绝加密包、绝对路径、`..` 越界、重复路径、Windows 保留名称、符号链接和目录联接。

限制：ZIP 文件最大 1 GB、解压总计最大 1 GB、单文件最大 64 MB、文件和目录合计最多 10000 个。实际解压长度和 CRC 都必须匹配。

先写临时目录并校验，再加入资料库。导入失败不改已有合集。程序不从 ZIP 执行任何文件。

## 编辑与交换

无需编写 JSON。编辑器使用目录、图片、说明文件保存资料；内部 JSON 仅保存布局、导入去重、回收记录。

工作库是事实来源，ZIP 是交换与备份副本。更改 ZIP 不会自动覆盖工作库；需要重新导入。相同 ZIP 内容用 SHA-256 识别，即使外部文件改名也不会重复导入。

将已导入合集重命名或删除后，再导入旧 ZIP 可以重新创建原始合集；导出与导入均不静默覆盖已有文件。

日常扫描上限：10000 个目录节点、累计 64 MB 说明；达到上限会停止并提示，保留已扫描结果。超大资料建议拆分到不同资料根目录，避免一次加载。元数据单文件最多 1 MB。仅支持普通本地磁盘路径，不支持 UNC、设备路径和备用数据流。
