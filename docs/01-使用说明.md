# 01 · 使用说明

## 首次运行

完整解压便携包，双击“道具手册.exe”。无需 Game Bar、Steam 或游戏运行，也不需要管理员权限。

软件在自身目录下建立：

| 目录 | 用途 |
| --- | --- |
| 图片包 | ZIP 收件箱与默认导出位置 |
| 资料库 | 导入或创建的可编辑合集，日常保存位置 |
| 用户数据 | 设置、导入去重记录、回收区 |

如果程序目录不可写，会让你选择一个可写资料根目录；选择记录保存在本软件的 LocalAppData 目录，后续继续使用它。

## 制作自己的合集

1. 点击“新建合集”，填写名称。
2. 在合集内点击“＋ 地图”，填写英文地图名，例如 Dust2、Mirage、Anubis。界面提供常用名称提示，可以自定义。CT/T 自动创建。
3. 在 CT 或 T 下点击“＋ 分类”，例如 A大；还可以继续创建更多层分类。
4. 在所需分类下点击“＋ 道具”，例如 A大防守烟。
5. 点击两个卡片上的“替换图片”，或把一张图片拖到对应卡片。
6. 编辑说明。停止输入约 0.65 秒后自动保存，底部显示保存时间。

图片会复制进资料库，移动外部原图不会影响软件。未添加齐两张图片的道具是草稿，默认不出现在查看列表。说明可以为空。

说明建议包含站位、瞄准点、左右键、是否跳投、移动方式及易错细节。这些都只是供你阅读的文字，软件不执行任何投掷操作。

## 调整目录

选择目录或道具后使用“重命名”“移动”“复制”“删除”。移动／复制会显示目标目录选择列表，不能移动到自身或覆盖同名内容。

删除进入回收区，可以恢复。CT/T 本身不允许重命名或删除；可以管理其下方内容。地图与合集可重命名或删除。

“打开所在文件夹”只打开选中的资料目录。外部编辑后点击“重新扫描”，重新加载内容。若软件里存在未保存文本，会先尝试保存；失败时保留文本并阻止切换。

## ZIP 导入导出

- 把包放进“图片包”，点击“图片包收件箱”选择；也可以点击“导入 ZIP”从任意用户指定位置导入。
- 导入自动解压并校验。相同 ZIP 会定位已有合集；同名不同内容会另建带编号的副本。
- 软件编辑的是资料库，不改原始 ZIP。
- 选择合集内任意节点，点击“导出合集”，生成新的 ZIP。目标文件已存在时需换名字，不覆盖原包。
- 导出前先完成说明保存。导入／导出执行期间暂时禁用编辑，防止相互覆盖。

## 后台快捷浏览

在编辑器先选择地图、CT/T、分类或道具，再点击“进入查看模式”。自行点击目标前台程序一次或 Alt+Tab 返回；手册不会替你转移焦点。之后打开菜单、切换高亮、进入目录和确认图片都不激活手册，鼠标继续穿透。

| 首次升级默认绑定 | 动作 |
| --- | --- |
| Ctrl+Alt+Q（沿用旧选择快捷键） | 打开／取消菜单 |
| 鼠标侧键 1（XButton1） | 上一项 |
| 鼠标侧键 2（XButton2） | 下一项 |
| 鼠标中键 | 确认／进入 |
| Ctrl+Alt+H（沿用旧显示快捷键） | 隐藏／显示图片 |

上下项首尾循环，每层都能“← 返回上一级”，一直返回合集列表。菜单仅列出包含完整双图道具的路径，草稿与空分类不会出现。一个目录既有道具又有子目录时，“查看本目录道具”与子目录分开列出。

菜单最多显示七行，随高亮滚动；不改变面板大小。高亮只是候选，确认道具才更新双图及说明并关闭菜单。再按菜单键取消会保留原图。隐藏键会取消浏览并隐藏整个面板；再次显示只恢复已确认图片。没有可用资料时，菜单键仍可关闭空状态。

菜单关闭时，上／下／确认键不导航。每次按下只触发一次，松开后才可再次触发；按住确认不会连续进入目录。重开菜单恢复上次目录和条目；在编辑器主动选择新的地图、阵营或道具会更新起始位置。

## 自定义输入

点击编辑器“快捷键”，再点击动作右侧的绑定，按下新键盘按键或鼠标按钮。可以绑定单键、左／右／中／两个侧键，以及 Ctrl、Alt、Shift 的组合。不支持滚轮、按键序列、多个普通键组合、Win 组合或单独修饰键。

重复绑定不能保存。可在草稿中交换两个动作的绑定，完成后点击“保存全部”；整组校验并写入成功才生效。关闭不保存或保存失败都会保留原绑定。录入期间可点击“取消录入”，也可关闭窗口放弃。

软件通过 Windows Raw Input 接收后台设备事件，不占用 RegisterHotKey，不拦截或转发输入。这些按键可能同时触发前台程序已有的动作，应选用你方便且能接受双响应的绑定。游戏是否响应取决于它自身，手册不补偿按键。

隐藏面板不会关闭使用模式，因此绑定在其他前台程序中也可能响应。返回编辑器、进入鼠标调整或退出软件会注销后台输入；本软件不检测当前应用。

## 鼠标调整与托盘

“图片查看”和“后台快捷浏览”始终穿透。“鼠标调整”只通过编辑器或托盘进入，可获得本软件焦点：
- 拖动标题移动，右下角改变大小。
- “横 / 竖”调整双图排列，分隔条调整说明高度。
- 双击图片放大，滚动阅读长说明。
- 调整透明度，以及“置顶 / 普通”显示方式。

点击“完成调整”恢复穿透和后台输入；需要时自行点击前台程序返回。快捷浏览按键不会进入鼠标调整。

托盘提供后台浏览、隐藏／显示、鼠标调整、资料编辑器、位置恢复和退出。编辑器关闭按钮收起到托盘，彻底关闭用托盘“退出”。后台注册失败会显示具体错误并停止快捷浏览，不改用钩子或轮询；托盘和编辑器仍可使用。

## 真实按键双响应验证

1. 从托盘退出旧版，启动新版、导入示例，选定道具后进入查看模式。
2. 双击发布目录中的“真实按键测试.cmd”；源码中也可运行“真实按键测试.ps1 -Published”。
3. 点击测试窗口使它保持前台。用真实绑定打开菜单，上／下／确认；检查前台动作计数增加、手册同时导航，测试窗口仍显示活动状态。
4. 按住确认只应增加一次；松开再按应再次响应。菜单取消不换图；隐藏后导航不选条目，显示恢复原图。
5. 将面板通过鼠标调整放在测试窗口下方的鼠标测试区域，再完成调整、点击测试窗口。移动和点击面板覆盖位置，检查下方标记和点击计数继续变化。
6. 检查隐藏／显示不抢焦点。更改绑定后重新打开测试窗口；测试计数不写入文件。

该窗口仅记录自身收到的绑定动作计数，不监视其他程序。自动测试不能替代以上真实操作。完成后再由你在 CS2 本地练习检查准心、同键响应与叠加显示；结果请自行记录，不等于官方安全认证。

## 从旧版升级

先通过托盘退出旧版，备份“资料库”“用户数据”，再完整解压新版到原目录覆盖程序文件。ZIP 不含这两个目录，保留已有内容；原两组快捷键、窗口位置和最近选择会迁移，新增三个导航动作使用默认鼠标键。也可复制这两个目录到新版目录后使用。原始图片 ZIP 不变；1.1.1 起拒绝双图和说明之外的附件。遇到旧包带附件，请在副本中移走额外文件后重新打包。

## 同屏显示遇到问题

先确认软件在普通桌面上能够置顶，再由你在游戏设置中查看显示模式。某些独占全屏场景不允许普通窗口显示在上方；可手动尝试窗口化全屏／无边框，也可以使用普通窗口通过 Alt+Tab 查看。

软件不检查游戏设置，不更改任何游戏文件，不提供绕过反作弊或强制覆盖独占全屏的办法。更换屏幕或分辨率后找不到面板，使用托盘“恢复面板位置”。

## 备份

定期导出合集 ZIP。要连同布局、最近选择、回收区一起备份，退出软件后复制整个资料根目录。回收区不会自动清空。


## 设置或权限出现问题

损坏设置会尽可能先备份到“用户数据/设置-随机编号.invalid.json”，再恢复有效默认值并提示。资料位置记录不可用时会尝试程序目录，必要时让你重新选择。窗口设置无法保存不会阻止退出，但未保存的道具说明仍受保护。图片替换若不能自动回滚，会保留旧图备份并显示所在路径。
