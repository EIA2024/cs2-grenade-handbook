# 03 · 技术边界与验证

## 自身代码边界

本软件只管理自己的窗口和用户选择的资料。不查询游戏进程、窗口、安装位置、配置、日志、内存或网络，不使用 GSI，不识别屏幕、地图或当前运行程序。

不注入 DLL、不使用游戏渲染或全局输入钩子、不安装驱动或服务、不模拟或转发输入、不控制游戏或反作弊设置。默认离线，无管理员权限要求。

## Windows API

| API | 用途与范围 |
| --- | --- |
| GetWindowLongPtrW / SetWindowLongPtrW / SetWindowPos | 仅对本软件创建的窗口检查或设置穿透、不激活样式 |
| RegisterRawInputDevices | 仅键盘 usage 6、鼠标 usage 2；目标为本软件窗口；使用 RIDEV_INPUTSINK，停止时 RIDEV_REMOVE |
| GetRawInputData | 读取本软件 WM_INPUT 设备事件，转换为五种已绑定命令 |

不注册 RIDEV_NOLEGACY、RIDEV_CAPTUREMOUSE、RIDEV_NOHOTKEYS。不与同一动作的 RegisterHotKey 并用，也没有全局输入钩子、轮询或模拟输入兜底。

HwndSource.AddHook 是本软件窗口的消息处理器，不是系统输入钩子。Raw Input 可在非前台时接收设备事件，见微软 [Raw Input 概述](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-raw-input) 和 [注册标志](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-rawinputdevice)。

输入类别注册后系统会发送该类别事件；软件忽略鼠标位移和滚轮，未匹配键立即丢弃，仅在内存保留修饰键及绑定键按下状态用于匹配和去重，不保存输入日志。返回编辑器、鼠标调整或退出时注销；隐藏仍处于使用模式。切换输入模式、更改绑定清空瞬态状态。

后台菜单、确认、隐藏／显示路径不调用 Activate 或 Focus，不解除穿透。编辑器及显式鼠标调整允许激活自身窗口；从不恢复或控制其他窗口的焦点。图片放大仅在鼠标调整下打开本软件对话框。

## 架构与数据

Handbook.Core 的 QuickNavigation 与 InputCommandMatcher 不依赖 WPF 焦点。IInputCommandService 将设备事件转为五个语义命令；IPresentationHost 管理 Viewing、Browsing、Adjusting。资料目录层级及双图/说明命名保持不变；1.1.1 起拒绝非规范附件。存储操作独立为 Handbook.Storage，Core 不直接读写磁盘。

设置版本 2 保存结构化绑定及浏览位置；旧设置迁移沿用两组键盘快捷键。整组绑定先验证、保存副本，再切换内存状态，失败保留原设置。

仅访问用户选择的资料、本软件设置和 LocalAppData 资料根目录记录。使用微软 .NET/WPF 与托盘组件，没有第三方业务库。构建时下载 SDK/运行时与日常离线运行分开。用户主动“打开所在文件夹”使用 Shell 打开资料目录。

## 自动验证和手动验证

自动验证涵盖 ZIP、编辑和保存回归，导航层级、循环、混合目录、过滤、取消／确认／隐藏语义，绑定合法性、迁移和失败保护，按下去重、释放、修饰键、状态清理，真实 Raw Input 注册／注销，以及本软件窗口样式和焦点状态。

窗口焦点测试只操作本项目自己的前台测试窗口，输入命令用内部方法调用；没有模拟硬件输入。界面图片是自身控件渲染，不采集屏幕。逻辑尺寸验证不等于切换真实 Windows DPI。

需用户用真实键鼠在独立“真实按键测试”窗口验证双响应与实际穿透。之后由用户在 CS2 本地练习验证准心持续控制、同键响应和叠加可见性。独占全屏、不同 DPI／显示器、实际帧率和游戏兼容均未由自动测试证实。

普通置顶无法覆盖时使用普通窗口或用户自行调整显示模式，不扩大权限或接入游戏。本软件未获得 Valve/VAC 官方认证，[Steam 用户协议](https://store.steampowered.com/agreement/?l=english)不代表对此类软件的免责保证。
