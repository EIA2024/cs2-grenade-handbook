# 06 · 开发者架构

当前版本 1.1.1。保持既有操作体验，按“业务规则 → 本地存储 → 桌面协调与适配”组织代码；暂不建设通用插件系统。

## 从哪里开始读

1. README.md：用户实际流程和资料规范。
2. Handbook.Core/Library：资料模型及仓储/包交换接口。
3. Handbook.Core/Navigation/QuickNavigation.cs：无焦点依赖的导航状态。
4. Handbook.Core/Input：绑定语义、按下去重和命令接口。
5. Handbook.Storage/LibraryRepository.cs、PackageService.cs：本地文件和 ZIP。
6. Handbook.Desktop/Program.cs → App/AppController.cs：启动、依赖组装与生命周期。
7. Presentation/ViewerWindow.cs、Editor/EditorWindow.cs：展示与编辑。
8. Windows：只有这里可以直接声明 Windows 原生输入/窗口接口。
9. Diagnostics：自检及用户真实按键测试入口。

## 依赖方向

~~~mermaid
flowchart TD
    Desktop["Handbook.Desktop<br/>编辑器 / 展示 / Windows 适配"] --> Storage["Handbook.Storage<br/>目录 / ZIP / 事务 / 元数据"]
    Desktop --> Core["Handbook.Core<br/>资料 / 导航 / 输入语义 / 设置规则"]
    Storage --> Core
~~~

Core 不依赖 WPF、文件系统操作或 Windows 原生接口。Storage 不依赖 Desktop，通过注入图片验证函数使用宿主的解码能力。Desktop 负责组装依赖。核心接口不包含游戏状态、进程、外部窗口句柄或游戏控制参数。

## 功能应该放在哪里

| 修改目标 | 主要入口 |
| --- | --- |
| 新的资料字段或规则 | Core/Library；同时维护 ZIP 兼容说明 |
| 导航或搜索规则 | Core/Navigation，不读取控件焦点 |
| 绑定、去重和输入命令 | Core/Input；真实 Windows 事件解析放 Windows |
| 新的存储实现 | 实现资料契约，不让 Core 引用磁盘或 WPF |
| 图片格式或说明读写 | Storage 校验与事务；Desktop/Presentation 解码 |
| 新展示方式 | Presentation 的 IPresentationHost；接收资料和显示设置 |
| 布局和操作控件 | Editor 或 Presentation，不直接加 P/Invoke |
| 原生能力 | 先核对 AGENTS.md，集中 Windows；禁止游戏访问、钩子及模拟输入 |

不要为未知未来需求提前加入插件加载、任意脚本执行、动态 DLL 加载或权限申请。确有另一种实现时再抽接口；不要用大量转发类隐藏简单调用。

## 数据与故障契约

- 日常编辑解压后的资料库，ZIP 只交换；不执行图片包中任何文件。
- 图片替换先准备新图、备份旧图，失败回滚；不能自动回滚时保留备份并显示路径。
- 元数据有界读取且拒绝链接；坏设置尽可能先备份，再恢复字段。
- 普通同用户桌面进程不是文件系统沙箱。路径检查不能消除恶意并发替换、所有硬链接或底层解码器缺陷。
- 不使用后台轮询、服务或管理员权限兜底。
- 输入注册失败即停止命令接收；编辑器和退出保留可用。未保存的说明继续保护；窗口设置写失败不阻止退出。
- 查看/后台浏览不激活窗口；显式编辑和鼠标调整可以激活本软件窗口。
- 导航、图片替换和设置迁移的行为变更需更新对应回归测试；布局小改不新增无意义测试。

## 构建、验收与发布

版本唯一来源为 Desktop csproj 的 Version。

~~~powershell
pwsh -File 构建.ps1
pwsh -File 验证.ps1
pwsh -File 构建.ps1 -Publish
pwsh -File 验证.ps1 -Published
pwsh -File 打包.ps1
~~~

发布先输出到全新构建目录，再建立包含每个运行时文件 SHA-256 的清单。打包只接受该清单中的程序文件，附上文档、占位示例和测试记录，不扫描收集使用目录中的任意 DLL/JSON。发布验证把清单哈希写入凭据；二进制或清单变化后需重新验证。哈希用于一致性检查，不是代码签名或官方认证。

构建暂存、历史版本和测试证据保留在 artifacts/测试结果，不是源码。源码变更集中 src，操作说明集中 docs；不在这些目录存个人资料。
